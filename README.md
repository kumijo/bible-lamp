# 말씀의 등불

일상의 상황과 마음에 맞는 킹제임스 성경(KJV) 말씀과 조언을 전해 주는 웹 앱입니다. 휴대폰 홈 화면에 설치할 수 있고, 한 번 열면 인터넷 없이도 동작합니다.

- 마음 나누기: 상황을 적거나 마음(불안, 지침, 관계·갈등 등 16가지)을 고르면 말씀과 한국어 풀이, 조언을 보여 줍니다.
- 성경 읽기·검색: KJV 66권 31,102절 전체를 읽고 영어 단어로 검색합니다.
- 간직한 말씀: 마음에 닿은 구절을 이 기기에 모아 둡니다.

Claude가 상황에 맞춰 말씀을 풀어 주는 기능은 claude.ai 버전에서 쓸 수 있습니다: https://claude.ai/artifact/FESqiPKL4F6TmAmTJ6xm59

본문: King James Version (퍼블릭 도메인), 데이터 출처 https://github.com/thiagobodruk/bible
